# Pragalbha Namrata — Professional Portfolio

Animated multi-portfolio site for **Pragalbha Namrata** — author (**Agnst_Ella**), content strategist & copywriter, and social media strategist for Rolling Authors®.

**Live site:** [https://pragalbha-namrata-portfolio.vercel.app/](https://pragalbha-namrata-portfolio.vercel.app/)  
**Repository:** [github.com/Monty25803/pragalbha-namrata-portfolio](https://github.com/Monty25803/pragalbha-namrata-portfolio) (private)

---

## Overview

| Portfolio | Focus |
|-----------|--------|
| **Author** | WebNovel / Wattpad fiction, ghostwriting samples, published works |
| **Copywriter** | Email, founder narratives, LinkedIn, SEO, brand & website copy |
| **Social** | Rolling Authors social systems — Instagram/LinkedIn strategy, campaigns, verified 90-day metrics |

Use the nav toggle to switch between **Author**, **Copywriter**, and **Social**. Each mode shows its own hero, about, stats, and portfolio.

---

## Highlights

- Dual-mode Author / Copywriter UI with Framer Motion
- Writing: novels with live read links, ghostwriting range, expertise areas
- Copywriting: services, email samples, founder narratives, brand stories, results
- Social: 2.04M Instagram views · 1.26M accounts reached (last 90 days), case studies, design galleries
- Experience timeline, skills, certifications, contact (email, LinkedIn, Fiverr, blog)
- Responsive layout for desktop and mobile

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Output: `dist/`
